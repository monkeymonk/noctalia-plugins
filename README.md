# Noctalia Plugins

A Noctalia v5 plugin source repository (Luau plugin API): each plugin lives in its own directory at the repo root, with a `plugin.toml` manifest and Luau entry scripts.

## Plugins

| Plugin | Description |
| --- | --- |
| [Fingerprint Manager](./fingerprint-manager/README.md) | Enroll, delete, and test fingerprints via `fprintd`. |
| [Niri Config](./niri-config/README.md) | View and edit your niri configuration from a panel - shortcuts, monitors and input, with a safe validate-backed save. |
| [Monique Profiles](./monique-profiles/README.md) | Switch monitor layouts via Monique profiles from the bar. |

## Installation

Add this repository as a plugin source, then install the desired plugin from Noctalia's plugin manager:

```bash
noctalia msg plugins source add monkeymonk git https://github.com/monkeymonk/noctalia-plugins
```

For local development, use a `path` source pointed at a local clone instead:

```bash
noctalia msg plugins source add monkeymonk path /path/to/noctalia-plugins
```

See each plugin's README for plugin-specific requirements and usage.

`catalog.toml` is auto-generated by CI from each plugin's `plugin.toml`; do not hand-edit it.
